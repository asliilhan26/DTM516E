# DTM516E – Quiz 1: Ship as a Wave Buoy (SAWB)

Estimation of significant wave height (Hs), peak period (Tp) and wave direction (Dp) from simulated 6-DoF ship motions with a multilayer perceptron (PyTorch).

**Notebook:** `DTM516E_Quiz1_SAWB_MLP.ipynb`

## Running
- **Colab:** open the notebook, put `project1_data.rar` in Google Drive ("My Drive"), uncomment the first code cell and run all cells.
- **Locally:** place the data at `data/project1_data/Data_Project1.npz` and run all cells.

Requirements: `torch numpy scipy scikit-learn matplotlib`

The dataset is not included in this repository because of its size.
